# Milestone 1 · Foundation: report

**Status:** done on 2026-10-31; merged into `main` (PR #1). The separate review is still to run (`tasks/todo.md`).
Scope: `tasks/plan.md` M1 (PLAN §8).

## What works

- **The contract, generated.** `api/tegola-lookup.openapi.yaml` (tegola's, byte for byte) generates the types and
  routes; `LookupAPI` implements all seven operations. Nothing outside the contract is routed.
- **App Attest, end to end.** Registration verifies the attestation against Apple's pinned root, the challenge, the
  app id, the environment and the key id; every secured call verifies an assertion over method, path and query,
  timestamp and body, with a strictly increasing counter. A fake CA and device (`AppAttestTestSupport`) run the real
  code in tests, one broken check at a time.
- **Security controls** (PLAN §5): fail-closed configuration with production and loopback as defaults; debug tokens
  refused by production at the edge; body cap; per-IP, per-key and registration rate limits; validation of every
  contract limit the generator skips; problem documents without internals; security headers; content-free logs.
- **Lookups** answer "no match" until sources arrive in M3 (D-12); match buckets are ready for them (D-13).
- **Tooling:** `scripts/test.sh`, `ci.sh`, `sync-contract.sh`, `lint-api.sh`, `secret-scan.sh`, `cloud-toolchain.sh`;
  CI on every push; a `Dockerfile` for a static binary running unprivileged.
- **tegola** says in its `CLAUDE.md`, D-41 and HANDOFF that this repo is the owner's and can be worked on from there.

## Found on the way

- The generated server percent-encodes string response headers: `Cache-Control` was unusable. Fixed with
  `CachePolicyMiddleware` (D-14).
- A body that doesn't decode is a 500 in the runtime; mapped to 400 (D-7).
- The pinned PEM first had one long line, which swift-asn1 rejects; the production server would not have started.
  `appleRootIsPinned` caught it.
- The contract didn't say how the body digest is written in the signed bytes, nor which bytes of the challenge are
  hashed. Both are now in the contract (D-5, D-6), in tegola first.
