(below). Scope: `tasks/plan.md` M3, with the sources the owner chose on 2026-11-01 (D-22).

## What works

- **Four sources behind `LookupService`**, each turned on by its own environment variables:
  - **Music, MusicBrainz:** barcode (exact hits only) and words (title, artist, catalogue number, year, format).
    Works are release groups.
  - **Video games, IGDB and ScreenScraper**, asked together: words only. IGDB gives one candidate per platform and
    region a game was released in, with its cover; ScreenScraper adds regional titles and retro coverage, without
    images.
  - **Board games, BoardGameGeek:** words only, two requests (search, then details of the best few).
  - **`thing`:** no source, as before.
- **Candidates fill the type files**: field keys and choice values from tegola's `music.yml`, `video-game.yml` and
  `board-games.yml`, and the subtype (vinyl, cd, cassette; n64, ps1, saturn, neo-geo, game-boy) when it's known.
  Every candidate names its source, with the attribution its terms ask for.
- **One ranking for every source**: title 70 %, subtitle 20 %, year 10 %, each counted when the query has it. D-13's
  import buckets work on it unchanged.
- **Failures are honest**: a source that is down, slow or over its quota answers 503 with `Retry-After`, never "no
  match". A second source for the same type keeps answering when the first fails.
- **Within each provider's terms**: a pace per source across all requests, a circuit breaker, timeouts, and a cache
  so the same barcode is asked once a day, not once per collector.
- **`/health` lists the types that have a source**, so the app knows which ones to ask.

## Security

Every rule of PLAN §5 holds for the new outbound side (D-22, "Security"):
- keys from the environment only, half-set pairs refused at start;
- the app's words can't change a provider's query (Lucene and IGDB escaping);
- ids are checked before they reach a URL;
- the Twitch secret never goes in a URL;
- ScreenScraper's credential-bearing media URLs are never passed on;
- images are kept only from each source's own host;
- XML is parsed without external entities;
- a failure logs a reason code, never the words, a URL or a key.

Each of these has a test that sends the attack and expects the refusal (`SourceTests`).
